Product Overview

MyNilam is an Indian real-estate rental + co-living marketplace. It connects tenants with verified flats, houses, commercial spaces, PG/hostel beds and roommate shares. The brand tagline is "Find Your Next Room."

The logo is the word "My" in slate, followed by the animated word "Nilam" (the word for "land") cycling through 5 languages: Nilam · നിലം · ज़मीन · நிலம் · أرض — rendered in an indigo-to-violet gradient.

Design Language (apply everywhere)

  • Glassmorphism + soft depth: white/90 (light) or slate-950/90 (dark) surfaces with backdrop-blur, rounded-3xl cards, border-2 border-black in light mode / border-slate-600 in dark mode, layered shadows and radial gradient glows (indigo and purple).
  • Fully responsive: desktop = 3-column + sticky sidebar; tablet = 2-column; mobile = single column with a fixed bottom action bar.
  • Light + dark mode both required.
  • Color system: primary indigo-600 (gradient indigo-600 → violet-700); hostels/PG accent purple-600 → pink-700; success emerald; availability emerald pill; danger red; warning amber; neutral slate-50 → 950.
  • Typography: heavy weights (font-black / font-extrabold) for headings and prices; tiny uppercase tracking-widest labels (10–12px) for micro-labels; prices in Indian ₹ formatting (e.g. ₹25,000/mo).
  • Micro-interactions: hover scale-105 on cards/buttons, active scale-95, animated fade-in, sticky header that hides on scroll-down and reappears on scroll-up.

Roles (each sees a different dashboard)

  • 1 Guest — browse only, no posting.
  • 2 Normal user (landlord/tenant) — post ads, favorites, inquiries, messages, visits, leases, maintenance.
  • 3 Employee — verify & publish pending listings.
  • 4 Super Admin — master catalog, employee register, user directory, hostel requests.
  • 5 Hostel Admin — manage a single hostel/PG.

Screen Flow

Screen 1 — Home / Catalog /

  • Sticky glass header (top): logo left; center nav "Find Properties · Dashboard · Settings"; right "Go Pro" pill, user name + role chip, logout icon, theme toggle, and a "Post Ad" gradient CTA.
  • Below header, a sticky glassmorphic tab switcher with two big segmented buttons: "PROPERTIES & ROOMS" (indigo gradient when active) and "HOSTELS & PGs" (purple gradient when active).
  • Hero section (Properties tab): centered badge "Verified Rentals & Co-living", giant heading "Find Your Next Room", subtitle, and a 4-stat grid (Listed Units 1,200+ · Matched Flatmates 500+ · Luxury Homes 150+ · Verification Rate 100%).
  • Filters sidebar (sticky, left, ~320px): search box, city, BHK/bedrooms, bathrooms, furnishing select, price min/max range, area range, property type, listing type, tenant preference, preferred gender, availability toggle, "freshness" (newest) toggle, verified-only toggle.
  • Listings feed (right): horizontal quick-filter pills (All Listings / For Rent / For Sale / Flat-Room Share), results count ("Showing N property results"), a view toggler (Grid / List / Map icons), and a sort dropdown (Newest / Price Low→High / Price High→Low).
  • Property card (grid + list variants): thumbnail image, "For Rent/Sale" tag + "Published/Pending" status pill, title, address + city, price in ₹, "View listing details →" link, remove button (owner/admin only).
  • Map view: full-width Leaflet/OpenStreetMap with property pins (Kochi, Kerala).
  • Empty state: dashed-border card with building icon — "No properties match your filters."

Screen 2 — Login /login

  • Centered glass card (max-width 448px), floating on a soft blurred indigo glow.
  • Shield icon, "Welcome back" heading, "Sign in or create a new one" link.
  • Email input (mail icon), Password input (lock icon), inline error pill (red).
  • Primary "Sign In" button, divider "OR", secondary "Continue as Guest" button.
  • (Dev-only) 4 quick-login chips: Normal User · Hostel Admin · Employee · Super Admin.

Screen 3 — Sign Up /signup

  • Same centered glass card style. Fields: full name, email, phone, password, confirm password, role selector.
  • Primary "Create Account" button + link back to login.

Screen 4 — Post Ad Wizard /post (4 steps + success)

Header: "Post Advertisement" + progress pill "Step X of 4".

  • Step 1 — "What type of ad is this?": 3 selectable cards (Rent Out · Sell Property · Find Roommate), each with icon, title, description, ring highlight when selected. Continue.
  • Step 2 — "Select category": grid of icon tiles (Apartment/Flat · House/Villa · Commercial · Hostel Space · PG/Co-Living · Plot/Land · Shared Room · Flat Share). Back + Continue.
  • Step 3 — "Listing specifications": Title, Description (char counter /1000), Price (₹), Area (sq.ft), Bedrooms, Bathrooms, Total Rooms, "Is Upstairs Unit?" checkbox, "Is Furnished?" checkbox (reveals Number of Beds + furniture checkboxes: Sofa, Dining Table, AC, TV, Fridge, Washing Machine, Microwave, Wardrobe, Gas Stove, Induction, Gas Connection), Utilities & Conveniences block (Water Source, Power Backup, Reserved Parking dropdowns), Tenant Preference + Preferred Gender dropdowns, "Gated Community?" checkbox, Security & Safety checkboxes (CCTV, Guard, Intercom, Fire). For Hostel/PG: gender restriction dropdown + room sharing capacity (1–6 share, dorm) + amenities checkboxes (Mess/Food, WiFi, AC, Laundry). Address, Landmark (optional), City/State/Zip, and a "Pin exact location on map" button (shows selected lat/lng). Continue (disabled until title/price/address/city set).
  • Step 4 — "Pricing, Contact & Media": Advance/Security Deposit (₹) input; "Use same contact details as profile" checkbox (uncheck reveals Contact Name + Contact Number); "Show contact details in listing" checkbox with privacy note; Photo drag-and-drop zone (PNG/JPG, max 10, "Browse Photos") and Video drag-drop zone (MP4/MOV/AVI, max 2, "Browse Videos"); uploaded photo preview grid with remove buttons. "Publish Listing" button.
  • Step 5 — Success: animated check, "Ad Posted Successfully!", note that listing goes live after staff verification, buttons "Go to Dashboard" + "Post Another".
  • Modal — Location picker: full-screen Leaflet map with draggable pin (default center Kochi 9.9312, 76.2673), "Confirm location" + close.

Screen 5 — Property Detail /properties/[id]

  • Top bar: "← Back to catalog" + Share button (copies link).
  • Hero: badges row (For Rent · X Beds Available · property type), title, location line (address, city, state · Near landmark), right-aligned Monthly Rent (₹ big, indigo) + Save heart button.
  • (Hostel/PG only) quick summary banner.
  • Left column (2/3): image gallery (main + thumbnails); property summary cards (rooms, bathrooms, area, furnishing, parking, etc.); (hostel) room-types & pricing breakdown with per-room "select" that opens a move-in summary drawer; "About the Property" description; amenities badges grid; video walkthrough (if present); location privacy section with map (exact pin locked until user requests — "unlock location" flow); reviews section (star rating, review list, "write review").
  • Right sidebar (1/3, sticky): pricing + availability card (Monthly Rent, "Available / N Beds Left" emerald pill, Security Deposit); owner contact + inquiry form card (name, phone/email — contact shown only if owner enabled it, otherwise "details shared after enquiry accepted"); "Schedule Visit" form (date, time, message).
  • Mobile: fixed bottom action bar with price + "Inquire Now" button (scrolls to inquiry form).

Screen 6 — Dashboard /dashboard (role-based)

  • Hero banner (dark slate): role chip ("Super Admin Access" / "normal role"), "Welcome, {name}", role-specific tagline, Post Property Ad CTA (non-guest), Log out button. (Non-guest) inline "Price Overview" mini bar chart (1/2/3/4 share prices).
  • Left sidebar (tab nav, icon + label + count badge), tabs by role:
    • My Ad Listings / Browse Properties / All Active Ads
    • Verify Listings (employee) · Employee Register (super admin) · User Directory (super admin)
    • Leases · Maintenance · Favorites · Inquiries · Messages · Visits
    • Hostel Requests (super admin) · Hostel Photos (hostel admin) · Hostel Management (hostel admin)
  • Main panel content per tab:
    • My Ads: card grid (status pill, title, address, price, view/remove).
    • Verify Listings: list of pending ads with "Verify & Publish" button; "All clean!" empty state.
    • Employee Register: add-employee form (name + email) + staff list.
    • User Directory: table of normal users with delete.
    • Favorites: saved property cards. Inquiries: received enquiries with accept/reject. Messages: real-time chat threads. Visits: scheduled visit requests. Leases: lease contracts list/detail. Maintenance: request categories + submit.
    • Hostel Management (hostel admin): full config form — hostel name, total beds/rooms, sharing types + per-share pricing, bathrooms, attached bathrooms, WiFi speed, hot water, water filter, mess, laundry, AC, address, city, price, gender type, vacant beds/rooms, water source.
    • Hostel Photos: upload/manage hostel photo gallery. Room/Bed grid editor.

Screen 7 — Settings /settings

  • Profile edit (name, email, phone), theme preference, password change, notification toggles, logout. Same glass card styling.

Responsive Rules

  • Desktop (≥1024px): 3-col detail layout, sticky sidebar, full header nav.
  • Tablet (768–1023px): 2-col grids, condensed nav.
  • Mobile (<768px): single column, header collapses, tab switcher full-width, filters become collapsible drawer, detail page gets fixed bottom action bar, wizard cards stack.
